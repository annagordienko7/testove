
## 1. Локальний запуск сайту (Docker)

Для розгортання серверів та автоматичного імпорту бази даних:

1. Завантажте всі файли цього репозиторію у пусту робочу папку на вашому комп'ютері. Переконайтеся, що файл `dump.sql` знаходиться в корені поруч із `docker-compose.yml`.
2. Відкрийте термінал у корені цієї папки та запустіть контейнери командою:
   ```bash
   docker compose up -d
   ```
3. Сайт автоматично імпортує базу даних `dump.sql` при першому старті та буде доступний у браузері за адресою:  
   👉 **http://localhost:8090**

## 2. Робота з темою та збірка асетів (NPM)

1. У терміналі перейдіть до директорії з кастомною темою:
   ```bash
   cd wp-content/themes/testove
   ```

2. Встановіть усі необхідні Node-залежності та пакети збірки:
   ```bash
   npm install
   ```

3. Запустіть режим постійного відстеження та автоматичної компіляції файлів (Watch mode):
   ```bash
   npm run watch
   ```

4. Для фінального стискання, оптимізації та мініфікації всього CSS/JS коду перед продакшеном використовуйте команду:
   ```bash
   npm run build
   ```
